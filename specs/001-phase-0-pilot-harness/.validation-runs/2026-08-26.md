### Meta-finding — checkbox freshness affects handoff reliability

The two attempts at Test 2.2 give first-hand evidence that cross-tool
handoff Q&A is sensitive to how eagerly checkboxes are updated in
tasks.md. With stale boxes, sessions build false reasoning around
"pending" tasks that are actually complete. With eager ticks, they
name the right task ID even if they miss the fine semantics.

**Implication for the harness**: eager checkbox updates after each work
unit are not bookkeeping niceties — they are load-bearing for reliable
handoff. This should be captured either as a workflow-level rule for
Phase 1+ operators or as an explicit line in CLAUDE.md's pointer block.
Deferred to Phase 6 polish (T034 candidate) as an ADR.
