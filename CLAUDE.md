# Project notes for haex-hive contributors

- User-facing prose in commits, issues, and pull-request descriptions is
  written in German. Technical identifiers (file paths, function names,
  config keys) stay in English. Constitution and spec-kit contract text
  is English by project convention.
- Prefer editing existing spec-kit or ADR files over creating new ones
  when the scope of a change fits within an existing scope.
